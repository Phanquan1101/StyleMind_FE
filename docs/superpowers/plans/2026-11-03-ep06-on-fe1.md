# EP06 trên nền FE-1

**Mục tiêu:** Đưa Friends, chia sẻ Outfit và Chat từ `E:/mss/du-an/FE` vào `E:/mss/du-an/fe-1/StyleMind_FE`, giữ Auth và Commerce của FE-1.

**Kiến trúc:** FE-1 là nền; chỉ chuyển phần EP06 và ghép thay đổi vào những file chung. Dùng phiên Identity hiện có cho API EP06, không dựng provider Auth thứ hai. Các lệnh Git do người dùng thực hiện; không tự commit, push hay deploy.

## 1. Kiểm tra trước khi sửa

- [ ] Người dùng kiểm tra trạng thái Git tại thư mục FE-1; giữ mọi thay đổi hiện có. Xác nhận thư mục nguồn và đích, lưu snapshot các file sẽ sửa.
- [ ] Chạy `npm run typecheck`, `npm test` và `npm run build` tại FE-1 để ghi nhận kết quả nền; phân biệt lỗi đã có với lỗi do tích hợp.

## 2. Giao diện và dữ liệu EP06

- [ ] Chuyển riêng `src/features/friends`, các component/model/test liên quan tới EP06 trong `messages` và `sharing`, `src/entities/friendship`, và các API EP06 từ `src/shared/api` ở nguồn; không chép đè cả thư mục.
- [ ] Ghép `src/app/store/types.ts`, `demoReducer.ts`, `demoSeed.ts` và `src/shared/storage/demoStorage.ts`: giữ action Identity/Commerce của FE-1 cùng Friends, visibility `friends` và đồng bộ dữ liệu EP06. Ghép `src/entities/outfit/model/types.ts` và các selector liên quan.
- [ ] Ghép `src/app/router/AppRouter.tsx`, `routes.ts`, layout/điều hướng và các màn hình Outfit: giữ route và provider FE-1; thêm Friends, lời mời, chia sẻ và Chat EP06. Chạy test Friends/Sharing và typecheck.

## 3. Phiên đăng nhập và API EP06

- [ ] Đọc `src/shared/api/identityApi.ts` và `IdentityAuthProvider`: thiết kế adapter EP06 sử dụng `readIdentitySession()` và quy trình refresh/đăng xuất hiện có; không tạo kho token riêng. Xác minh request cũ không làm mất phiên mới.
- [ ] Ghép proxy `/wardrobe-community` bao gồm WebSocket vào `vite.config.ts`, giữ proxy Identity và Commerce của FE-1. Bật chế độ API EP06 có kiểm soát, bảo đảm không gửi ID demo sang backend.
- [ ] Ghép API Friends và lời mời, kiểm tra trạng thái loading/lỗi và luồng sau đăng nhập. Khôi phục, điều chỉnh các test API đang bị skip để dùng phiên Identity thật giả lập.
- [ ] Ghép API Outfit visibility, danh sách và chi tiết; kiểm tra PRIVATE/FRIENDS/PUBLIC, quyền và liên kết public, giữ nghiệp vụ FE-1 ngoài phạm vi.
- [ ] Ghép Chat text, lịch sử, ảnh và STOMP; kiểm tra token ở CONNECT, gửi lại, hủy kết bạn, thu hồi URL ảnh và reconnect. Không đưa token vào URL.

## 4. Xác minh và bàn giao

- [ ] Chạy test Auth, Commerce, Friends, Sharing, Chat; sau đó `npm test`, `npm run typecheck`, `npm run build`. Báo riêng lỗi nền, lỗi mới và test còn skip.
- [ ] Kiểm thử thật qua Gateway khi backend sẵn sàng: đăng nhập, kết bạn, chia sẻ Outfit, chat text/ảnh, logout và refresh. Nếu chưa chạy backend, ghi rõ chưa xác minh end-to-end.
- [ ] Rà các file thay đổi, tài liệu tích hợp và ảnh hưởng Auth/Commerce; bàn giao kết quả cho người dùng tự quyết định Git/PR. Không xóa dữ liệu hay dùng credential thật trong test.
